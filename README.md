## 📖 项目简介

这个项目的初衷非常单纯：作者在制作 **公路 POV (Point of View)** 视频时，发现寻找或制作符合规范的中国道路标识极其麻烦。在被现有的低效率流程折磨之后，决定自己动手，丰衣足食。

本项目其实只是本人出门拍公路 POV 每次找道路标识都很麻烦所以实在是受不了了决定自己造轮子的产物。在本仓库创建前，已经通过 **Vibe Coding** 实现了一个不是很好用的 Python 版本，但是由于实在是不好用且不方便，决定现在重新开一个仓库重构整个轮子到 Web 端，以后可能会打包成一个 Electron 程序也说不定。

---

## ✨ 主要功能

* [x] **高度自定义**：支持路名、编号、距离等信息的实时修改。
* [x] **标准配色**：内置高速绿、国道红、省道黄等标准色板。
* [x] **即时预览**：所见即所得，通过 Canvas 实现高清晰度渲染。
* [x] **一键导出**：支持导出图片格式，方便直接拖入剪辑软件。

---

## 🛠 技术栈

* **Frontend**: HTML5 / CSS3 / JavaScript
* **Graphics**: Canvas API
* **Methodology**: **Vibe Coding** (Powered by AI)
